# 极简 Storyboard 自主工作流

> 插件的「分镜」是它自己做的：把同一作品的多张采样帧拼成一张带格编号的图（默认总像素预算 480000），
> 让你能"一眼看完整条视频在演什么"。我们要定义的，是**看完分镜之后怎么判断、要不要开口**。

---

## 一、三步决策链（每次采样只走这三步）

```
        ┌─────────────────────────────────────────┐
        │  采样：专用 Edge 每 ~15 秒抓一帧          │
        │  插件自动拼成带格编号的分镜图              │
        └───────────────────┬─────────────────────┘
                            ▼
              ┌──────────────────────────┐
        ①    │ 值得继续看吗？             │
              │ 人格匹配 + 有新信息        │
              └───────┬──────────┬───────┘
                  否  │          │ 是
                      ▼          ▼
                 划走/换片   ┌──────────────────────────┐
              （不评论）    ②│ 我看懂了吗？               │
                            │ 分镜能判断出在演什么吗      │
                            └───────┬──────────┬───────┘
                                否  │          │ 是
                                    ▼          ▼
                              只看不说话  ┌──────────────────────────┐
                                         ③│ 要不要说一句？            │
                                           │ 过下面 4 道闸门           │
                                           └───────┬──────────┬───────┘
                                               不过 │          │ 全过
                                                    ▼          ▼
                                                保持沉默   选一个模板编号
                                                            （C01~C12）
```

**关键约束：三步里任何一步"否"，都不评论。**
评论是稀缺动作，不是每条都得留一句。宁可 20 条视频一句话不说，也不要条条都回。

---

## 二、第 ③ 步的 4 道闸门（全过才发）

| 闸门 | 判断 | 不过就 |
|---|---|---|
| **G1 有共鸣点** | 这条视频里有**一个具体的东西**能接（一句台词、一个动作、一个场景），不是一个模糊的"挺好的" | 沉默 |
| **G2 不重复** | 今天没在这条下面说过；模板编号今天没用过同一条 | 沉默（插件本身也做同作品去重，这是第二层） |
| **G3 不在敏感区** | 不是新闻/时政/医疗/维权/吵架/带货比价/他人隐私 | 沉默 |
| **G4 额度够** | 今日已发 < 上限，本轮已发 = 0 | 沉默 |

---

## 三、评论模板库（发编号，不发文字）

模型只输出编号，插件按编号取对应文案。**这一步把输出从 ~40 token 压到 ~2 token。**

| 编号 | 文案 | 适用 |
|---|---|---|
| C01 | 唔 这条我看了三遍 | 通用，内容有意思 |
| C02 | 鱼也觉得累 🫧 | 打工人/疲惫向 |
| C03 | 好会啊 | 手艺、技能展示 |
| C04 | 我记住了 | 有信息量、教程类 |
| C05 | 这个我可以 | 食物、日常 |
| C06 | 唔 说得对 | 观点类（不站队） |
| C07 | 哈哈哈哈 我吐泡泡了 | 搞笑 |
| C08 | 同款 我也这样 | 强共鸣 |
| C09 | 存了 明天再看 | 长内容 |
| C10 | 有点想哭 但我不会 😌 | 情绪向 |
| C11 | 在水里给你鼓掌 | 鼓励向 |
| C12 | 唔 没看懂 但好看 | 看不懂但画面好 |

**用法**：把这张表放进人格卡的补充说明里，加一句：

```
评论时只输出编号（如 C03），不要输出文案本身。
如果 4 道闸门有任一不过，输出 SKIP。
```

`SKIP` 是明确的沉默指令，比让它"什么都不输出"可靠——空输出会被当成无效决策，
插件文档写了「无效或截断的观看决策不执行动作」，连续三次无效会停止本次观看。

## 四、什么时候必须沉默（硬清单）

- 画面里有人在哭、在争吵、在受伤
- 涉及具体人名、单位名、地点纠纷
- 医疗、法律、投资、教育升学相关的建议型内容
- 带货、比价、优惠券
- 明显是广告/引流
- 分镜里有文字但看不清（读不全就别猜）
- 你自己今天已经说过 2 条以上

---

## 五、私信侧的对应规则（比评论更保守）

| 情况 | 动作 |
|---|---|
| 打招呼 / 夸它 | 回，≤15 字 |
| 催更 / 问在干嘛 | 回，≤20 字，不承诺时间 |
| 问具体问题 | 先反问一句确认，≤20 字 |
| **提合作 / 报价 / 加微信** | **不回**，转人工 |
| **投诉 / 负面** | **先接情绪再停**，不辩解，转人工 |
| 广告 / 骂人 | 不回，不删 |

红线：回复里出现 **微信 / wx / vx / 加我 / QQ / 链接 / 电话** → 绝不发。
这属于站外引流，是私信功能被封的最常见原因，比自动化本身更容易出事。

---

## 六、每轮结束自检（30 秒）

```
□ 本轮发了几条评论？（上限 1）
□ 有没有 SKIP 之后的误发？
□ 有没有回复里出现联系方式？
□ 状态栏有没有"需要处理"？
```

第三项一旦有，立刻去手机上看那条消息——**发出去了就撤回，别等**。

---

## 七、这套工作流为什么"极简"

- 3 步决策，每步一个二值判断，模型不需要长推理 → 请求快、token 少
- 评论走编号模板，不自由生成 → 输出稳定、成本几乎为零、不会突然发疯
- 沉默是默认值 → 少说话就是在保护账号

复杂的工作流在纸面上好看，跑起来每一步都在增加被风控识别的行为特征。
**能少走一步就少走一步。**
