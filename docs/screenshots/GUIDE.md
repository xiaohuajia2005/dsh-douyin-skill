# 演示截图指引

README 里不放占位图（避免出现裂图）。截图统一放 `docs/screenshots/`，
文件名为 `01-demo.png` 这种格式，**不要用中文名**。

原图（含未脱敏信息）放 `docs/screenshots/raw/`，该目录已在 `.gitignore` 里。

---

## 硬规则：先脱敏，再截图

**必须遮掉**：抖音号、头像、昵称、对方昵称、二维码、手机号、地理位置。

**允许保留**：时间、状态文字、你自己写的消息内容、命令行输出。

判断标准：**把这张图发给陌生人，他能不能找到这个账号或这个人？**
能，就还得遮。

三个最常被忘的地方：

1. 浏览器窗口标题栏（可能带账号名）
2. 地址栏（`douyin.com/user/xxxx` 里有 sec_uid）
3. 右下角消息气泡上的小头像

---

## 五张图，按这个顺序拍

### 01 · 离线演示（必拍，零风险）

```bash
python -m skill.cli demo
```

终端拉宽到 120 列以上，保证表格不折行。截整屏，包含底部"对照原版行为"那几行
—— 那四行是这套改动最直接的证据。

> 这张图不需要任何账号，建议作为 README 首图。

### 02 · 测试通过（必拍，零风险）

```bash
python -m skill.cli selftest
```

截最后 5 行（`Ran 41 tests` / `OK`）。别截全长，没人看中间的过程日志。

### 03 · 陌生人消息：原版 vs 本版（最核心）

**这张要两张并排或上下拼接。**

- 上半：原版插件下，陌生账号发"你好呀，刷到你的视频了" → 无任何响应，状态栏无变化
- 下半：本版，同一句话 → 观察期受控回复"唔 在的 你说 🫧"

拍法：用两个小号。A 号发消息给机器人，先关掉适配层截一张，
再打开适配层重发（换条消息内容，避免幂等键命中）截一张。

拼图时左侧加文字标注"原版：静默丢弃" / "本版：观察期回复"。
**这是面试官唯一会仔细看的一张。**

### 04 · 会话异常期间的消息队列

制造一次异常（最简单的方式：在插件运行时切换 Edge 标签页几秒，
或临时断网再恢复），然后看两件事：

- 会话状态变成"退避中"或"停机"
- 期间进来的消息出现在待发队列里，**不是消失**

截图要能同时看到状态和队列。如果界面看不到队列，就用 `var/audit/*.jsonl` 的
`tail` 输出代替，并注明"这是审计日志"。

### 05 · 撤回后待发失效

对方发一条消息后立刻撤回（5 秒内），截图要体现：
待发列表里那条记录没了，或者审计日志里出现 `"action": "recalled"`。

审计日志是最容易拍也最可信的证据，优先用它。

## 可选：不做也别硬凑

- 视频观看的播放列表截图：信息量低，且容易泄露推荐流里的他人内容。
- 点赞/收藏的计数截图：说明不了任何工程问题。
- 私信对话长截图：脱敏成本极高，收益很低。

宁可只有 01、02 两张干净的，也不要五张糊的。
