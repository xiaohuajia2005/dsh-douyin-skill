# 1.4.12 本地更新

自主分享会先查一件事：这条作品是不是对方自己发过来的。如果某位许可对象此前把这条作品发给过大肥鱼，就不再回发给同一位对象——回发是重复，也影响交流观感。

记录由聊天轮询在发现入站作品卡片时写入：会话编号、作品编号、消息编号、时间。作品编号优先取卡片上的编号，其次从公开链接取；编号与链接互相矛盾、或卡片已标身份冲突的一律不记，宁可不判重复也不记错。只存这四个字段，不存标题、作者、画质采样或聊天正文。

只在 30 天内算「刚发过来的」，更早的入站不再阻止回发；同一对象同一作品只留一条，重复收到不会把窗口一直往后挪；记录最多 3000 条。命中时记一条 `watch.share-skipped`（`SHARE_ALREADY_RECEIVED`）继续处理其余对象和观看，不写分享账本、不占发送次数。

模型侧也能提前看到：分享上下文新增 `receivedRecipients`，观看决策说明里会写「这条作品是这些对象发过来的，不要再回发给同一对象」。但记录正文不进提示词，硬跳过仍在分享服务里做，模型改不了这个判断。

读不到或读到损坏的记录文件时只当作没有记录、照常分享，不会因为一次读盘出错停掉观看。未确认的发送收据、许可撤回、证据变化和不在允许时段仍按原规则停止。当前只更新本地插件与独立软件，尚未公开发布。
